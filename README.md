# ZJ Panel

ZJ Panel is a Minecraft server management panel with Docker-backed server management, file management, console, backups, nodes and administration features.

## VPS installer

Run the included installer as root:

```bash
sudo bash install.sh
```

The installer menu is:

1. **Install Panel** — installs dependencies, Docker, Node.js, builds ZJ Panel and creates a systemd service.
2. **Install Wings** — installs the latest stable Pterodactyl Wings binary and systemd service. A node configuration must still be generated by the panel before Wings can start.
3. **Update** — backs up panel data, updates/rebuilds the panel and updates Wings when installed.
4. **Uninstall** — removes services and optionally removes files/data after an explicit confirmation; a backup is kept under `/var/backups/zj-panel`.
5. **Add Domain** — creates an Nginx reverse proxy, checks DNS and can request a Let's Encrypt certificate.
6. **Exit**.

### Important domain note

The installer can configure the web panel domain, Nginx and SSL. It cannot change DNS at your registrar without that provider's API credentials. Create an A record pointing the domain to the VPS first.

### Wings note

Wings is a separate daemon. Installing its binary does not create a valid node configuration or secret token. Generate the node configuration from the panel and save it as `/etc/pterodactyl/config.yml` before starting Wings.
